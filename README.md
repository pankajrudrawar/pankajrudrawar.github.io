# pankajrudrawar.github.io

Source for [pankajrudrawar.github.io](https://pankajrudrawar.github.io), the catalog of my Terraform modules for AWS and Azure storage.

The site is a single static `index.html` with inline CSS and no build step. Edit the file, commit to `main`, and GitHub Pages publishes it.

## Preview locally

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
